# 📊 Electronics Sales Analysis | Power BI

## 📌 Overview

This project analyzes electronics sales data using Power BI to uncover insights into sales performance, profitability, product performance, and customer behavior.

## 🛠️ Tools

* Power BI
* Power Query
* DAX
* Microsoft Excel

## 📈 Key Analysis

* Total sales and profit analysis
* Profit margin calculations
* Sales performance by product and region
* Customer and sales representative analysis
* Sales trends over time
* Currency conversion and data cleaning

## 🎯 Objectives

* Clean and transform sales data.
* Develop an effective data model.
* Create interactive dashboards and visualizations.
* Generate insights to support business decision-making.
